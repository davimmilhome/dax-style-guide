# dax-style-guide

Este é o repositório que hospeda o documento que tem como objetivo propor um padrão formal de desenvolvimento, abordando convenções de nomenclatura, estruturação de consultas, boas práticas de modelagem e formatação DAX, tudo voltado ao uso do Power BI Desktop.


[dax-style-guide](https://davimmilhome.github.io/dax-style-guide/)

Atualmente o guia está sendo desenvolvido em português (focado na comunidade brasileira), porém, será traduzido para o inglês em algum momento.

## Filosofia do projeto

Para contribuir com este repositório é necessário ler a filosofia do projeto. 

[Filosofia do Projeto](https://davimmilhome.github.io/dax-style-guide/docs/filosofia-do-projeto/)

## Como usar
    - Clone o repositório;
    - Na pasta do projeto, instale as dependências Ruby (necessário ter Ruby + Bundler instalados): `bundle install`;
    - Execute o servidor local: `bundle exec jekyll serve --baseurl ""`

</br> 

Todavia, observe que é possível utilziar o projeto, e até mesmo contribuir,  sem executar o servidor local (sem ruby e outras depedências) apenas editando os arquivos `.md`. 



## Tecnologias utilizadas
     - ruby
     - jekill 
     - just-the-docs
     - github pages


## Contribuindo

Para contribuir no projeto, primeiramente abra uma issue para justificar a sua contribuição, em seguida, em uma branch com sua modificação solicite o Pull Request (PR) atrelando a issue especificada, utilize convetional commits em inglês.

</br>

O PR será avaliado com relação a sua coerência com o projeto, certifique-se que está de acordo com a [Filosofia do Projeto](https://davimmilhome.github.io/dax-style-guide/docs/filosofia-do-projeto/). Além disso, descreva as alterações no changelog do projeto. 

</br>  

Também sinta-se a vontade para deixar sua issue para debater um ponto em específico ou solicitar alterações, alterações que não necessariamente serão atendidas, mas discutidas de forma aberta.
